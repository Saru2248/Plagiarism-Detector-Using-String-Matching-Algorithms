1. Knuth-Morris-Pratt (KMP) Logic

The KMP algorithm processes the pattern to generate the LSP failure table. By knowing repeating components within the string, it skips redundant index checks during text search operations.

Time Complexity: O(N + M) | Space Complexity: O(M)

2. Rabin-Karp Polynomial Hash Formulas

Rabin-Karp turns matching operations into numbers. Substrings of length $M$ are evaluated as a base-$d$ base polynomial representation modulo a large prime $q$ to check for duplicate content.

Pattern Hash Formula:
Hash(P) = (P[0]*d^(M-1) + P[1]*d^(M-2) + ... + P[M-1]*d^0) % Modulo

Rolling Hash Math (O(1) Shift):
Hash(Next) = (d * (Hash(Prev) - OutgoingChar * d^(M-1)) + IncomingChar) % Modulo

3. Set Similarity (Jaccard and Containment)

To catch modified or rearranged paragraphs where exact string searches fail, set math evaluates overall content overlaps.

  • Jaccard Similarity Index: Intersection divided by Union of words: $\frac{|A \cap B|}{|A \cup B|}$. Catches overall vocab matches.
  • Containment Score: Intersection divided by size of submission set: $\frac{|A \cap B|}{|A|}$. Identifies paragraphs copy-pasted into massive reference text databases.
